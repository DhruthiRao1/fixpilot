---
title: HP boot device menu (Please select boot device)
vendor: HP
topic: boot
---
The "Please select boot device" menu on HP consumer laptops appears when F9 (or Esc then F9)
is pressed during power-on. It lists UEFI boot entries such as "OS Boot Manager (UEFI) -
Windows Boot Manager" and "Boot From EFI File". Pressing Enter on Windows Boot Manager starts
Windows normally. F10 opens BIOS Setup; Esc exits.

If the menu appears without the user pressing any key, a startup hotkey is usually stuck or
was pressed while switching on, which is common after cleaning the keyboard. No firmware
setting needs to change. If a USB drive is plugged in but not listed, the drive is either not
bootable UEFI media or is being blocked by Secure Boot.
