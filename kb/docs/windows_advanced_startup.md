---
title: Reaching UEFI firmware settings from Windows 11
vendor: any
topic: bios
---
If startup hotkeys are hard to time (for example POST HotKey Delay is 0), open
Settings -> System -> Recovery -> Advanced startup -> Restart now. On the blue "Choose an
option" screen select Troubleshoot -> Advanced options -> UEFI Firmware Settings -> Restart.
Do not select "Reset this PC" unless you intend to reinstall Windows. "Continue" exits to
Windows.
