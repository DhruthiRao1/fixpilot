---
title: HP BIOS Setup Utility - Boot Options tab
vendor: HP
topic: bios
---
HP consumer BIOS (AMI, e.g. HP Laptop 15-dy2xxx, BIOS F.33) has tabs Main, Security,
Configuration, Boot Options and Exit. It is keyboard-only: arrow keys move, Enter opens a
field's option list, F5/F6 change values or move a device down/up in UEFI Boot Order. With
Action Keys Mode enabled, F5/F6 may require holding Fn.

Boot Options fields: POST HotKey Delay (sec) (0, 5, 10, 15, 20 - chosen from a list, not
typed), USB Boot, Network Boot, Network Boot Protocol, Secure Boot, Platform Key, Pending
Action, and UEFI Boot Order (OS Boot Manager, USB Flash Drive/USB Hard Disk, USB CD/DVD ROM
Drive, USB Network Adapter). Devices marked "!" have boot disabled. Save with Exit -> Save
Changes and Exit.
